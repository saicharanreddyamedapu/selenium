# Selenium Hands-on Learning Repository

This repository contains my hands-on learning journey in Selenium automation testing. I have practiced and explored the following Selenium concepts and techniques to build a strong foundation in web automation testing.

## Core Selenium Concepts Covered

- Selenium WebDriver basics
- Browser automation using Chrome, Edge, and Firefox
- Locating elements using:
  - ID
  - Name
  - Class Name
  - Tag Name
  - Link Text
  - Partial Link Text
  - CSS Selectors
  - XPath
- Interacting with web elements such as:
  - Textbox input
  - Button clicks
  - Radio buttons and checkboxes
  - Dropdowns and multi-select lists
- Handling dynamic web elements
- Browser navigation and page interactions
- Working with frames and iframes
- Handling alerts, pop-ups, and confirmation dialogs
- Switching between windows and tabs
- Capturing screenshots for debugging and reporting
- Working with waits:
  - Implicit Wait
  - Explicit Wait
  - Fluent Wait
- Handling JavaScript-enabled pages and actions
- Mouse and keyboard actions using Action class
- Drag and drop operations
- Scroll operations and element visibility checks
- Working with multiple browser sessions and test execution flows

## Automation Framework Concepts

- TestNG and JUnit for test execution
- Page Object Model (POM)
- Page Factory design pattern
- Reusable helper and utility classes
- Data-driven testing
- Test configuration and environment setup
- Assertions and validation techniques
- Test case structure and execution flow
- Reporting and test results analysis

- Verifying search, filter, and pagination actions
